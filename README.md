# 🚀 Prometheus & Grafana Monitoring Stack

A complete Windows monitoring solution built using **Docker**, **Prometheus**, **Grafana**, and **Windows Exporter**.

This project demonstrates how to collect real-time system metrics, visualize them through interactive dashboards, and configure automated email alerts for proactive monitoring.

---

# 📌 Project Overview

This monitoring stack performs the following tasks:

- Collects Windows system metrics
- Stores metrics in Prometheus
- Visualizes metrics in Grafana
- Uses PromQL for custom monitoring
- Sends email alerts when CPU usage exceeds the configured threshold
- Sends automatic recovery emails once CPU usage returns to normal
